Dépose ici ta compagne 3D. Deux formats :

1) VRM (.vrm) — par ex. VRoid Hub
   Choisis un modèle dont la licence indique « Expression sexuelle : autorisée ».
   GoonFap retire les vêtements et prépare une peau nue tout seul.

2) MMD (.pmx) — mets le DOSSIER COMPLET du modèle :
     modele/HIME/HIME.pmx
     modele/HIME/tex/…   modele/HIME/sp/…   modele/HIME/toon/…
   Sans ses textures, le modèle est invisible ou gris.
   Les animations .vmd se jouent nativement dessus, avec la physique (cheveux, seins).
   Le strip-tease retire les vêtements qui sont des pièces séparées du corps.
   Un .pmx ne contient pas de licence lisible : vérifie-la toi-même (readme du modèle).

Le personnage doit être clairement ADULTE.
S'il y a plusieurs modèles, choisis lequel dans le popup (rubrique 💃).
Ensuite : chrome://extensions → « Recharger » sur GoonFap.
Ce dossier n'est jamais envoyé sur GitHub.
